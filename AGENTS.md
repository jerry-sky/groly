# Agent / contributor notes

- Run Node.js, **`pnpm`**, and other project tooling **only inside the Docker dev environment** (for example the `groly-dev` service in `docker-compose.dev.yml`), so the toolchain matches CI and production.
- **Do not use `npm`** in this repository. Use **`pnpm`** for installs and scripts when working in the container.
- Inlang **Paraglide** output is regenerated by the **`paraglideVitePlugin`** in `vite.config.ts` whenever you run the dev server or a Vite build. Do **not** rely on manually running `paraglide-js compile` during normal development; editing `messages/*.json` and saving is enough while `pnpm dev` is running.
